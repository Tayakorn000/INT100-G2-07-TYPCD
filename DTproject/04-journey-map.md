# Journey Map — ผู้ใช้สวนสาธารณะออกกำลังกาย/ฟื้นฟูสุขภาพ

| ขั้นตอน | สิ่งที่ทำ | ความรู้สึก |
| --- | --- | --- |
| 1. เดินทางมาสวน | วัยทำงาน: ออกจากที่ทำงานหลังเลิกงาน / ผู้สูงอายุ: เดินทางมาตามรอบสัปดาห์ | กลาง ๆ |
| 2. ถึงสวน | หาที่จอดรถ/ที่เก็บของ (วัยทำงาน) หรือแวะเข้าห้องสมุดก่อน (ผู้สูงอายุ) | ต่ำ–ขึ้น แล้วแต่คน (ต่ำสุดถ้าวันไหนคนเยอะ) |
| 3. เริ่มกิจกรรม | เปลี่ยนชุด อบอุ่นร่างกาย เริ่มวิ่ง/เดินรอบแรก | ขึ้น |
| 4. เจอปัญหาระหว่างทาง | วัยทำงาน: วิ่งช่วงพีค (17:30–19:00) คนแน่น แดดแรง ร่มเงาไม่พอ / ผู้สูงอายุ: ต้องเดินอ้อมจุดน้ำเน่าส่งกลิ่น | ต่ำ (จุดต่ำสุดของหลายคน) |
| 5. ออกกำลังกายจบ | วิ่ง/เดินครบระยะที่ตั้งใจ เหงื่อออก รู้สึกสดชื่น (ผู้สูงอายุ: อาการเวียนศีรษะดีขึ้น) | สูงสุด |
| 6. กลับ/ช่วงเย็น-ค่ำ | เดินทางกลับ ช่วงพลบค่ำแสงไฟไม่ทั่วถึงบางจุด บางคนเคยรู้สึกไม่ปลอดภัยหรือเคยโดนแซวตอนเดินคนเดียว | กลาง ๆ ถึงต่ำมาก (ต่ำสุดถ้าต้องอยู่คนเดียว) |

**จุดต่ำสุดของ journey:** ขั้นตอนที่ 2/4 สำหรับกลุ่มวัยทำงาน (หาที่จอดรถ, คนแน่น, แดดแรง — "แย่งเวลา" ออกจากเวลาออกกำลังกายจริงของคนที่มีเวลาจำกัด) และขั้นตอนที่ 4/6 ที่เป็นจุดร่วมข้ามทุกกลุ่มอายุ คือปัญหาสิ่งแวดล้อม (น้ำเน่า) และความปลอดภัยช่วงแสงน้อย — ยิ่งเห็นชัดว่าเรื่องแสงไฟ/ความปลอดภัยตอนพลบค่ำไม่ใช่ปัญหาเฉพาะกลุ่มใดกลุ่มหนึ่ง แต่เป็นปัญหาของสวนสาธารณะโดยรวม
