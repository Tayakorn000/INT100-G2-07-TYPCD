# Journey Map 2 — ผู้สูงอายุเดินออกกำลังกายที่สวนธนบุรี

| ขั้นตอน | สิ่งที่ทำ | ความรู้สึก |
| --- | --- | --- |
| 1. ออกจากบ้าน | เดินทางมาสวนธนบุรี (สัปดาห์ละ 1 ครั้ง) | กลาง ๆ |
| 2. เริ่มเดิน | เริ่มเดินออกกำลังกายรอบสวน | ขึ้น |
| 3. เจอจุดน้ำเน่า | ต้องเดินอ้อมหลีกเลี่ยงจุดที่ส่งกลิ่นเหม็น | ต่ำ (จุดต่ำสุด) |
| 4. แวะห้องสมุด | เข้าใช้บริการห้องสมุดในสวน | ขึ้น |
| 5. เดินจบ 30 นาที | เหงื่อออก รู้สึกสดชื่น อาการเวียนศีรษะดีขึ้น | สูงสุด |
| 6. (กรณีเย็น/ค่ำ) | เดินในพื้นที่เปลี่ยว เคยโดนแซว | ต่ำมาก |

**จุดต่ำสุดของ journey:** ขั้นตอนที่ 3 (จุดน้ำเน่า) และขั้นตอนที่ 6 (ความไม่ปลอดภัยช่วงค่ำ) — ทั้งสองจุดบั่นทอนสิ่งที่ควรเป็นกิจกรรมฟื้นฟูสุขภาพให้กลายเป็นประสบการณ์ที่ต้องระวังตัวแทน
