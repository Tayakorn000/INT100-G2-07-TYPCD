# User Persona

**ชื่อ:** อ้น (ตัวแทนกลุ่มคนทำงานออฟฟิศที่วิ่งในสวนสาธารณะ)
**อายุ:** 46 ปี
**อาชีพ:** พนักงานออฟฟิศ ทำงานใกล้สวนสาธารณะที่ไปวิ่งเป็นประจำ

## Goal
ออกกำลังกาย (วิ่ง) ให้ได้ระยะตามที่ตั้งใจ โดยเสียเวลาเดินทางน้อยที่สุด เพราะมีเวลาว่างจำกัดแค่ช่วงเย็นหลังเลิกงาน

## Behavior
- เลือกสวนสาธารณะที่ใกล้ที่ทำงานที่สุดเป็นอันดับแรก
- มาวิ่งเป็นประจำ ไม่ใช่ครั้งคราว
- ให้ความสำคัญกับ "ระยะทาง/พื้นที่ที่พอเหมาะกับการวิ่ง" มากกว่าสิ่งอำนวยความสะดวกอื่น

## Pain point
- เวลาที่มีให้ออกกำลังกายจำกัดมาก (ช่วงเย็นวันธรรมดาเท่านั้น)
- ความไม่สะดวกใด ๆ ที่เกิดขึ้น (พื้นที่แออัดช่วงเวลาเร่งด่วน, หาที่จอดรถ) กระทบเวลาออกกำลังกายที่มีน้อยอยู่แล้วโดยตรง
- ช่วงเย็นแดดยังแรง ร่มเงาตามเส้นทางวิ่งไม่พอ ต้องลดจังหวะหรือหยุดพักบ่อยกว่าที่ตั้งใจ
- แสงไฟส่องสว่างไม่ทั่วถึงบางจุดช่วงพลบค่ำ รู้สึกไม่ปลอดภัยเวลาต้องวิ่งคนเดียว

## Insight

1. คนทำงานออฟฟิศเลือกสวนจากระยะทางจากที่ทำงานเป็นเกณฑ์หลัก ไม่ใช่คุณภาพหรือบรรยากาศของสวน เพราะเวลาออกกำลังกายมีแค่ช่วงเย็นหลังเลิกงาน
2. ทุกความไม่สะดวกระหว่างทาง (หาที่จอดรถ, พื้นที่แออัด) กระทบเวลาออกกำลังกายที่มีน้อยอยู่แล้วโดยตรง ไม่ใช่แค่ความรำคาญทั่วไป
3. ร่มเงาตามเส้นทางเป็นปัจจัยที่กระทบคุณภาพการวิ่งช่วงเย็น เพราะแดดยังแรงในช่วงเวลาเดียวที่พวกเขามีให้ออกกำลังกาย
4. ความปลอดภัยช่วงพลบค่ำเป็นข้อกังวลที่ทำให้บางคนวิ่งได้ไม่เต็มที่หรือรีบกลับก่อนถึงระยะที่ตั้งใจ

## Quote
> "ตรงนี้มันกว้าง มันได้ระยะที่เหมาะกับเรา แล้วก็ใกล้ที่ทำงานด้วย"
